# 26.3 native normal-view control

Developer fixture, not a shader pack compatibility claim or a distributable mod.
Adapted from the repository's native-terrain oracle, without its green multiplier.
Exercises actual terrain/shadow GLSL, an HDR auxiliary marker and fullscreen
presentation. A magenta oracle result is failure; an ordinary view alone is not
proof of BSL/Complementary support, correct shadows or long-term stability.

Copy this folder to the isolated runtime-audit shaderpacks directory. Never
replace an existing user's pack or normal game profile for this test.
