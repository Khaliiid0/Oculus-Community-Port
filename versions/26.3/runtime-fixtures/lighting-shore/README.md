# Local-only lighting/shore controls

Install only in the new isolated `installed-audit/lighting-shore-20261118` copy
of the disposable gameplay save, while closed. There are no load/tick tags.
The five explicit `/function oculus_lighting:<day|sunset|night|rain|clear>`
commands set only time/weather. They do not freeze time, alter blocks, install
resource packs or change player graphics. Locate/choose an actual natural shore
through in-game observations; record the camera and keep it fixed across states
and pack replacements. Do not call a constructed flat-world pool a natural shore.

These are visibility/colour/recovery smoke observations, not image parity or an
FPS benchmark. Pack defaults mean unchanged original ZIPs with no option sidecar.
