# Local-only fog-distance controls

Manual functions, no LOAD/TICK tag and no block edits. Install only in the
separate fog-range diagnostic world copy. They hold clear day and place the
player at fixed ray-aligned poses inferred from the archived GPU readback.
Yaw=0/pitch=15. Not an independent Iris reference, pixel oracle or performance test.
Use d_restore before saving/exiting, then archive this datapack and the separate
automatic stage bootstrap outside the world's active datapack directory.
